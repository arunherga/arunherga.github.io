# Skill logo sources

These logos identify technologies in Arun's toolkit. All trademarks belong to their respective owners; their appearance does not imply endorsement.

- Python, Go, Bash, Ansible, Linux, Docker, Kubernetes, Terraform, AWS, Azure, Apache Kafka, MySQL and Microsoft SQL Server: [Devicon](https://github.com/devicons/devicon/tree/7330accdbc47e2dc0c19789a48533c4a3c50fe58/icons). Original SVG variants, except AWS uses `original-wordmark`. Distributed under the included `DEVICON-LICENSE.txt` (MIT).
- Docker Compose: [official project logo](https://github.com/docker/compose/blob/023544aae7553386f8fc73186cf08931fbb49bd5/logo.png). See `DOCKER-COMPOSE-LICENSE.txt` and `DOCKER-COMPOSE-NOTICE.txt`.
- OpenTofu: [official symbol for light backgrounds](https://github.com/opentofu/brand-artifacts/blob/589e4111bcf8de39fae9dfb2b8659f7f5373a92b/symbol-only/transparent/SVG/on-light.svg). See `OPENTOFU-LICENSE.txt` (MPL-2.0 and trademark notice).
- Temporal: [official brand assets](https://temporal.io/brand), [dark logomark SVG](https://images.ctfassets.net/0uuz8ydxyd9p/3B1zR4imcNyF9oHQxT06AD/9fce8b9ead280e66c21805c58d115176/Temporal_Symbol_dark.svg).

Artwork is served locally. Temporal's SVG viewBox trims excess empty canvas; its paths and colors are unchanged. All other artwork is stored unchanged. Display dimensions are set in CSS, and the adjacent text supplies each skill's accessible name.
