# Skill logo sources

These logos identify technologies in Arun's toolkit. All trademarks belong to their respective owners; their appearance does not imply endorsement.

- Python, Go, Bash, Ansible, Linux, Docker, Kubernetes, Terraform, AWS, Azure, Apache Kafka, MySQL and Microsoft SQL Server: [Devicon](https://github.com/devicons/devicon/tree/7330accdbc47e2dc0c19789a48533c4a3c50fe58/icons). Original SVG variants, except AWS uses `original-wordmark`. Distributed under the included `DEVICON-LICENSE.txt` (MIT).
- Docker Compose: [official project logo](https://github.com/docker/compose/blob/023544aae7553386f8fc73186cf08931fbb49bd5/logo.png). See `DOCKER-COMPOSE-LICENSE.txt` and `DOCKER-COMPOSE-NOTICE.txt`.
- OpenTofu: [official symbol for light backgrounds](https://github.com/opentofu/brand-artifacts/blob/589e4111bcf8de39fae9dfb2b8659f7f5373a92b/symbol-only/transparent/SVG/on-light.svg). See `OPENTOFU-LICENSE.txt` (MPL-2.0 and trademark notice).
- Temporal: [official brand assets](https://temporal.io/brand), [dark logomark SVG](https://images.ctfassets.net/0uuz8ydxyd9p/3B1zR4imcNyF9oHQxT06AD/9fce8b9ead280e66c21805c58d115176/Temporal_Symbol_dark.svg).

- Helm, Java, Grafana, and Elasticsearch (representing the ELK stack): original SVGs from the same pinned Devicon revision and MIT license above.
- Strimzi and Flux CD: [CNCF artwork](https://github.com/cncf/artwork/tree/831f27a0cf4227b1b76a28ff51a9f4127a2195ec/projects), color icon variants. See the repository's artwork and trademark guidance.
- Debezium: [official project artwork](https://github.com/debezium/debezium.github.io/blob/731be53f3d66adf568965670d5a2327e63a824c3/assets/images/color_black_debezium_type_600px.svg). The viewBox isolates the symbol from the wordmark; paths and colors are unchanged.
- Confluent Platform and Cloud: [official Confluent touch icon](https://www.confluent.io/icons/apple-touch-icon.png).
- Kustomize: an original configuration-layers SVG symbol, not a vendor logo. It illustrates Kustomize's configuration overlays.
- OpenSearch and PagerDuty: [Simple Icons](https://github.com/simple-icons/simple-icons/tree/d0b3c2d7153794b912913746fc0498a5d3211727/icons), under the included `SIMPLE-ICONS-LICENSE.md` (CC0). Fill colors match the project's brand metadata: `#005EB8` and `#06AC38` respectively.

Artwork is served locally. Temporal's SVG viewBox trims excess empty canvas; its paths and colors are unchanged. Apart from the display adjustments noted above, artwork is stored unchanged. Display dimensions are set in CSS, and the adjacent text supplies each skill's accessible name. AWS and Azure logos also identify the EKS and Event Hubs experience described in the resume.
